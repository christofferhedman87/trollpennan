# B1.1 – Dela `src/spel/angen3d.tsx` (ren flytt, noll beteendeändring)

**Avsikt:** spelaren märker ingenting, men scenkoden ligger i små filer så att nya platser (Skogen, Sjön, Grottan) kan läggas till.
**Skills:** threejs, building-games. Installera dem först om de saknas.

**Ritning, i prioritetsordning:**
1. Skapa `src/spel/ang/delat.ts` med alla konstanter, hjälpfunktioner och hooks från `angen3d.tsx` r.1–206 och `usePennTryck` (r.~1305). Exportera dem.
2. `src/spel/ang/dekor.tsx`: `Sond, Moln, TradOchBlommor, Granar, Fjarilar, Ringar, Nackrosor, Eldflugor, GrasTuvor, Stenar, Ljusflackar, Glitter, FagelFlyg, Hanglas, Rok, Horisont, Forgrund`.
3. `src/spel/ang/byggnader.tsx`: `Hus, Byggnad, SpokHus, Skogsstig`.
4. `src/spel/ang/djur.tsx`: `Formdel, DjurForm, Hjartan, DjurIScen`.
5. `src/spel/ang/saga.tsx`: `SagaKamera, SagaLjus, SagaPenna, SagaBoll, SagaKanin`. `src/spel/ang/himmel.tsx`: `Himmel, SvajMark`. `src/spel/ang/kamera.tsx`: `KameraRam`.
6. `angen3d.tsx` behåller bara `Scen` och `Angen3D` och importerar resten. Signaturen `Angen3D({ natt, saga })` är oförändrad, så `Spel.tsx` rörs inte.
Ingen fil får bli över 800 rader. Flytta koden ordagrant och ändra bara importer och exporter. Ändra inget annat och lägg inte till några funktioner.

**Skrivregel:** gör första ändringen inom 10 verktygsanrop, och kör inga mätskript. Committa efter varje steg (`B1.1: steg N`). Om turerna börjar ta slut, skriv `rundor/BLOCK-platser/RUNDA-B1.1.md` innan du gör något annat.

**Om tiden inte räcker:** steg 1–4 räcker. Committa och rapportera vad som återstår.

**Spärrar:** ingen `setState` i `useFrame`. Rör inte `data-testid`. Lägg inte till nya beroenden.

**Visa att:**
1. `npm run test:product`, `npm run typecheck:pages` och `npm run build:pages` är gröna.
2. `wc -l src/spel/angen3d.tsx src/spel/ang/*` visar att ingen fil är över 800 rader.
3. `rg -o 'data-testid="[^"]+"' src/spel -g '*.tsx' | sort | md5sum` är samma före och efter.
4. Bilderna `rundor/BLOCK-platser/b1-1-01-angen-375x812.png` (ängen med tre djur) och `b1-1-02-natt-375x812.png` ser likadana ut som före flytten. Ta bilderna med Playwright mot `dist-pages`, efter `npm run build:pages`.

**Slutbedömning:** skriv `rundor/BLOCK-platser/RUNDA-B1.1.md` med vad som inte är klart, de tre svagaste ställena och risken för B1.3b. Committa och avsluta.
